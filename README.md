# mcp-neo4j-biomechanisms

Empirical Neuroscience Knowledge Graph MCP Server — how conscious experience is expressed in biological substrate.

## Quick Start

```bash
uv sync --dev
mcp-neo4j-biomechanisms --db-url bolt://localhost:7687
```

## What This Is

A purpose-built MCP server for empirical neuroscience knowledge graphs. Maps what peer-reviewed science says about consciousness's biological substrate, connected as the science connects it, with no interpretive overlay. GDS reveals structural patterns invisible to sequential reading.

8 node types, 12 relationship types, ~16 tools. All mutations through bounded tools — no raw write access.
