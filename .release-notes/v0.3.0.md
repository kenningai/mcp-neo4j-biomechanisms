# v0.3.0 — MIT license

`mcp-neo4j-biomechanisms` is now released under the MIT License.

`LICENSE` sits at the project root and the license is declared in package metadata under PEP 639, so both distributions carry `License-Expression: MIT` and ship the license text at `dist-info/licenses/LICENSE`. The build backend floor moves to `hatchling>=1.27`, the first release supporting those fields — relevant only if you build from source.

## Also in this release

- `compose.yml` adds a second service exposing the upstream `mcp/neo4j-cypher` server on `:8004` against the same Neo4j instance, so the biomechanisms tools and general Cypher access are available side by side. Telemetry is disabled on both services.
- `Dockerfile` and `compose.yml` version pins move to `0.3.0`, and the compose image name follows the repository to the `kenningai` organisation.

## Validation

- `uv run pytest tests/unit` — 55 passed. No Neo4j required; validation logic is pure Python and tested without a database.
- Both the wheel and the source distribution install into a clean environment and run the entry point.
